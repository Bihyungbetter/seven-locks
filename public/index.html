How this works

Each lock has its own random password. The Lockkeeper doesn't remember anything between questions, so every question has to work on its own. Each lock, the Lockkeeper is under stricter orders, and it doesn't always manage to keep them: if it lets the password slip, it's yours. The last lock picks a new password every time you guess wrong.

Answers come from OpenAI's gpt-5.4-mini, so don't type anything private.
